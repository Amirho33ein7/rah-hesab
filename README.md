# راه‌حساب | دفتر هوشمند درآمد راننده

وقتی چند شیفت، ساعت کاری و کیلومتر طی‌شده داری، حساب‌وکتاب نباید خودش تبدیل به دردسر بشه.

«راه‌حساب» ساخته شده تا همه‌چیز رو یک‌جا مدیریت کنی:

⏱️ ثبت ساعت شروع و پایان شیفت  
🛣️ ثبت کیلومتر و محاسبه مبلغ آن  
💰 محاسبه خودکار درآمد هر شیفت  
📊 گزارش روزانه و ماهانه درآمد، ساعت و مسافت  
📅 تاریخچه کامل رکوردها و مشاهده روزهای مختلف  
⚙️ تنظیم جداگانه تعرفه ساعت و کیلومتر  
✏️ ویرایش رکوردهای ذخیره‌شده با محاسبه مجدد  
💾 ذخیره‌سازی محلی و پشتیبان‌گیری از اطلاعات  
🌙 رابط کاربری فارسی، RTL و مناسب موبایل

از ثبت یک شیفت تا دیدن درآمد کل ماه، همه‌چیز ساده، سریع و یک‌جا.

**راه‌حساب؛ چون وقتت برای حساب‌وکتاب اضافه نیست. 🔥**
